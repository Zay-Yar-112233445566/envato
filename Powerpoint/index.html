Folder Structure

  • style.css - main style.css
  • The css folder - contains the CSS for all major browsers, prettyphoto, responsive to site makes responsive for all devices and the font awesome (Please ensure that your new styles are applied. Also make sure that they carry enough "weight" and there isn't a style lower in the CSS file that is being applied after yours.)
  • The fonts folder - contains the font awesome font files.
  • The images folder - contains all the images that are being used in the stylesheets for the layout purpose and it has a subfolder like blog-images, portfolio-images, which contains images used in posts, pages and other areas
  • The skins folder - contains the CSS for 20 predefined color skins that comes along with this template.
  • The php folder - contains the contact form mail sending code & Mailchimp subscription form integration code.
  • The js folder - contains javascript files and plugins as follows,
    1. jQuery framework (jquery.js)
    2. jQuery Sticky Nav, Donutchart plugin for rounded progress bar, Parallax Scrolling, Number animation, Inview plugin for animation purpose, Skin Chooser plugin (jquery.plugins.min.js)
    3. Isotope plugin for portfolio filters (jquery.isotope.min.js)
    4. Google Map plugin (jquery.gmap.min.js)
    5. PrettyPhoto plugin for lightbox preview (jquery.prettyPhoto.js)
    6. Contact Form (contact.js)
    7. BX Slider for Portfolio Single Page (jquery.bxslider.min)
    8. Skin Chooser plugin (controlpanel.js)
    9. Testimonail (jquery.carouFredSel-6.2.1-packed.js)
    10. Twitter plugin for latest Twitter Feeds (jquery.tweet.min.js)
    11. For Tabs (jquery.tabs.min.js)
    12. Validation plugin for form validation (jquery.validate.min.js)
    13. For ToolTip (jquery.tipTip.minified.js)
    14. Back to Top (jquery.ui.totop.min.js)
    15. Easing (jquery-easing-1.3.js)
    16. For Layer Slider
      1. jquery-transit-modified.js
      2. layerslider.kreaturamedia.jquery.js
      3. greensock.js
      4. layerslider.transitions.js
    17. And custom js like (custom.js)

Full-width & Boxed Layout



For Boxed Version, Please add the boxed class inside the body tag as shown below. We have 15 different patterns and 3 images in the image folder. If you wish to add your own pattern instead of the default pattern,then just place you own pattern in the images folder. After that you can call the pattern imageas shown in the below example.

Example

        <body class="boxed" style="background-image:url(images/patterns/pattern1.jpg);">

Light & Dark



For Dark Version, Please add the dark-skin.css.

Example

        <link media="all" rel="stylesheet" href="dark/dark-skin.css" id="light-dark-css">

Note

1. name attribute should be "frmcontact"

2. action attribute should be "php/send.php"

3. How to change the email address to receive mails (to address only receivers email)?

Please open "php/send.php" at line no: 4

$to = 'xxx@xxx.xx'; #Replace your email id

Subscribe Form

Note

1. Name attribute should be "frmsubscribe"

2. Action attribute should be "php/subscribe.php"

$mcapi = new MCAPI('PUT YOUR API KEY HERE...');   $list_id = 'PUT A VALID LIST ID...';  #Replace your api key & list id

Fonts

We have used Google Fonts (Roboto, Roboto Condensed ) in our template. You can use any Google font simply as following,

1. Please replace the following lines in all layout files.

            
            @import url(http://fonts.googleapis.com/css?family=Roboto:400,300,700|Roboto+Condensed:400,700);

2. Find the following lines in style.css and replace with your new font family.

 
			body, input[type="text"], textarea, select, p { font-family:'Roboto', sans-serif; }	
	
            h1, h2, h3, h4, h5, h6, h1.section-title, #main-menu ul.menu > li > a { font-family:'Roboto Condensed', sans-serif; }
            
            .dt-sc-testimonial-carousel li, #contact-form.type2 input[type="text"] { font-family: 'Open Sans', sans-serif; }
            
			.dt-sc-testimonial h4 { font-family: 'Open Sans Condensed', sans-serif; }
